# Что нужно сделать вручную

Подробные инструкции по выкладке, домену и релизам лежат в [README.md](README.md). Здесь только список.

## Первые шаги на GitHub (аккаунт shoz1t)
- [ ] Создать репозиторий `shozit-site` (сайт и лаунчер), в **Settings → Pages → Source** выбрать **GitHub Actions**.
- [ ] Создать репозитории `rigged` и `deep-roll` (в них будут только релизы).
- [ ] В репозитории `rigged` создать релиз `v0.1.0` и загрузить `test-builds/RIGGED-v0.1.0-windows.zip` и `RIGGED-v0.1.0-linux.zip`.
- [ ] В репозитории `deep-roll` создать релиз `v0.1.0` и загрузить `test-builds/DeepRoll-v0.1.0-windows.zip` и `DeepRoll-v0.1.0-linux.zip`.
- Хэши и размеры в `site/version.json` уже посчитаны для этих четырёх архивов. Если пересоберёшь архив, запусти `node tools/release.mjs game ...` (см. README), он обновит хэш.
- Архивы собраны из `assets/rigged/source/builds/demo-easter-eggs-credits` (10 октября) и `assets/deeproll/source/builds` (18 августа). Это прямые файлы игр, не установщик из папки `release/`.

## Лаунчер
- [ ] Выпустить первый релиз: тег `launcher-v0.1.0` (команды в README, раздел 4).
- [ ] После релиза выполнить `node tools/release.mjs launcher 0.1.0 <установщик Windows> <AppImage>` и отправить `site/version.json`: так хэши лаунчера попадут на сайт.
- [ ] Проверить лаунчер на настоящем Linux (X11 и Wayland): изменение размера за края, видео-фон, запуск игры. Я проверял только интерфейс в браузере с заглушкой и тесты загрузки на Windows.
- [ ] В Linux видео-фон нужен кодек VP9 (пакет gstreamer1.0-plugins-good). Если его нет, фон не показывается, остальное работает.
